# Exercicios Praticos

### Exercicio 1
Crie uma tela de Login contendo: Usuário e Senha.

Considere que o sistema somente vai entrar se as informações forem:

```
Usuário: login
Senha: 1234
```

O programa deve verificar as informações e retornar **Login feito com sucesso** ou **usuário ou senha inválidos**

---


### Exercicio 2
Crie um formulário que receba 5 número:

O programa deve descobrir
- Maior número
- Menor número
- soma dos números
- qantidade de numeros pares
- quantidade de numeros impares.

### Exercicio 3
Crie um sistema de caixa.

Usuário deverá informar:

- preço do produto
- Quantidade 
- Forma de pagamento

As formas de pagamento serão:

- Pix
- Dinheiro
- Cartão

**Regras:**
- Pagamento em dinheiro: 10% de desconto
- pagamento em pix: 5% de desconto
- Pagamento em Cartão: sem desconto

**Resultado do programa:**
- Subtotal
- Desconto
- Total

**Desafio**
Se o pagamento for em dinheiro, silicite também o valor entregue pelo cliente e calcule o troco;
