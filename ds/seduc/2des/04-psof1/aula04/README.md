# Tutorial de Gitpage

1. Criar o arquivo HTML 

Dentro do repositório, clique em Add file.

Selecione Create new file.

Digite o nome index.html.

Insira o código HTML da sua página.

Clique em Commit changes para salvar.

2. Ativar o GitHub Pages

Acesse a aba Settings do repositório.

No menu lateral, clique em Pages.

Na seção Build and deployment, localize Source.

Selecione Deploy from a branch.

Em Branch, selecione main.

Em Folder, selecione / (root).

Clique em Save.

3. Acessar o site

Aguarde alguns minutos para a publicação.

Acesse novamente Settings > Pages.

Localize o endereço disponibilizado pelo GitHub.

Clique no link para visualizar seu site.

O endereço seguirá este padrão:

https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/
