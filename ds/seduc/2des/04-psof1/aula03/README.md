# Atividade

Selecionar uma metodologia ágil para o desenvolvimento do seu projeto e estruturar a equipe com os papéis necessários para aplicá-la de forma eficaz.

## Instruções:

### 1. Escolha da Metodologia:

- Pesquise e escolha uma das metodologias ágeis estudadas: Scrum, Kanban, Extreme Programming (XP) ou Lean Development.

- Justifique a escolha explicando como essa metodologia se encaixa no projeto que sua equipe desenvolverá.

### 2. Definição do Projeto:

- Determine um software a ser desenvolvido (exemplo: aplicativo de delivery, plataforma de ensino online, sistema de gestão empresarial, etc.).

- Descreva brevemente o propósito do software e seus principais objetivos.


### 3. Montagem da Equipe:

- Com base na metodologia escolhida, defina os papéis essenciais na equipe de desenvolvimento.

- Distribua as funções entre os membros (por exemplo: Product Owner, Scrum Master, Desenvolvedores, Testadores, Designers, etc.).

- Explique a função de cada papel dentro do time e como contribuirá para o sucesso do projeto.

### 4. Elaboração do Planejamento Inicial:

- Crie um cronograma ou roadmap inicial baseado na metodologia escolhida.

- Indique como serão feitas as entregas e revisões do software ao longo do desenvolvimento.

### 5.	Apresentação da Atividade:

- Cada grupo deverá preparar um pequeno documento ou apresentação explicando suas escolhas e como irão aplicar a metodologia escolhida na prática.
