- Entrada
- Processamento
- Saída

## 3. Variáveis

Explique a diferença entre:

- Inteiro
- Real
- Caractere
- Lógico

## 4. Operadores

- Operadores aritméticos
- Operadores relacionais

## 5. Estruturas de Decisão

- SE
