# 📬 Mala direta + Tabelas


## Tabelas no Word

As **tabelas** no Word são estruturas organizadas em linhas e colunas que permitem apresentar dados de forma clara e visualmente acessível.

### Para que servem:
- Organizar informações (ex: cronogramas, listas, comparações)
- Criar formulários ou fichas
- Estruturar dados para relatórios e documentos técnicos

### Como funcionam:
1. Vá em **Inserir > Tabela**
2. Escolha o número de linhas e colunas
3. Preencha os dados conforme necessário
4. Use as ferramentas de **Design** e **Layout** para personalizar bordas, cores e alinhamento



## Mala Direta no Word

A **Mala Direta** é um recurso que permite criar documentos personalizados em massa, como cartas, etiquetas, certificados ou e-mails, usando uma fonte de dados (como uma planilha do Excel).


### Para que serve:
- Enviar comunicações personalizadas para vários destinatários
- Automatizar certificados, convites, contratos, etc.
- Reduzir erros e economizar tempo em tarefas repetitivas

### Como funciona:
1. Prepare uma **fonte de dados** (ex: Excel com nomes, endereços, etc.)
2. No Word, vá em **Correspondências > Iniciar Mala Direta**
3. Escolha o tipo de documento (ex: cartas, envelopes, etiquetas)
4. Clique em **Selecionar Destinatários** e conecte sua fonte de dados
5. Insira os **campos de mesclagem** (ex: `<<Nome>>`, `<<Endereço>>`)
6. Visualize os resultados e finalize com **Concluir e Mesclar**

## Exercício de Avaliação de Notas

Você deverá realizar as seguintes tarefas:

1. **Abrir o Excel** e criar um banco de dados de alunos.
2. O banco contém as seguintes colunas:
   - Nome
   - Português
   - Matemática
   - Física
   - Espanhol
   - História
   - Responsável
   - Instituição
   - Ano Letivo
Preencha as colunas com pelos menos 10 linhas de informação.


3. **No Word**, crie um boletim individual para cada aluno com os seguintes elementos:
   - Cabeçalho com o nome da instituição e o ano letivo.
   - Texto de apresentação com o nome do aluno e do responsável.
   - Tabela com as notas por disciplina.
   - Texto de encerramento.
   - Campos para assinatura do responsável e da escola.

4. **Padrão deve ser da ABNT de margens, fontes, tamanhos...**

5. **Imprima** todos os boletins em PDF e salve na área de trabalho com o nome de BoletinsAlunos.docx
