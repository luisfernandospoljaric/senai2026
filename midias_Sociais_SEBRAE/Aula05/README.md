# Ferramentas de Vetorização no Canva

## Criação e Edição de Imagens para Mídias Sociais

Material didático sobre conceitos de vetorização e utilização de elementos vetoriais no Canva.

---

# 1. Objetivos da aula

Ao final desta aula, o aluno deverá ser capaz de:

* Entender o que é uma imagem vetorial.
* Diferenciar imagem bitmap de imagem vetorial.
* Identificar elementos vetoriais dentro do Canva.
* Utilizar formas, linhas, ícones e gráficos como elementos vetoriais.
* Criar desenhos utilizando formas geométricas.
* Redimensionar elementos sem perder qualidade.
* Alterar cores de elementos gráficos.
* Trabalhar com camadas.
* Agrupar e organizar elementos.
* Criar uma composição utilizando elementos vetoriais.
* Criar um logotipo simples utilizando formas e elementos gráficos.

# 2. O que é vetorização?

**Vetorização** é o processo de transformar uma imagem ou desenho baseado em pixels em uma representação baseada em vetores.

Uma imagem vetorial é formada matematicamente por elementos como:

* Pontos;
* Linhas;
* Curvas;
* Formas;
* Preenchimentos;
* Contornos.

Por utilizar informações matemáticas para representar os elementos gráficos, uma imagem vetorial pode ser ampliada ou reduzida sem apresentar a mesma perda de qualidade característica das imagens bitmap.

### Exemplo

Uma imagem bitmap pode apresentar perda de qualidade quando ampliada:

```text
Imagem pequena
      ↓
    LOGO
      ↓
   Ampliar
      ↓
Imagem pode ficar pixelada
```

Já uma representação vetorial pode ser redimensionada mantendo seus contornos definidos:

```text
Elemento vetorial
       ↓
      LOGO
       ↓
    Ampliar
       ↓
Continua com contornos definidos
```
