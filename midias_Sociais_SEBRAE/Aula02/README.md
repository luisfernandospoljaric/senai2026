# Borracha Mágica do Canva

A **Borracha Mágica** é uma ferramenta do Canva utilizada para **remover elementos indesejados de uma imagem**. Ela utiliza inteligência artificial para identificar a área selecionada e tentar reconstruir o espaço que ficou vazio.

Ela pode ser utilizada para remover:

- Pessoas ao fundo de uma fotografia;
- Objetos;
- Placas e textos;
- Pequenas manchas;
- Elementos que distraem na imagem;
- Objetos indesejados em cenários;
- Alguns detalhes presentes no rosto ou corpo.

> **Importante:** o resultado depende bastante da imagem. Quanto mais complexa for a área removida, maior pode ser a dificuldade do Canva para reconstruir o espaço corretamente.

---

## 1. Como acessar a Borracha Mágica

Primeiro, abra o Canva e crie ou abra um projeto.

### Passo 1 — Adicione uma imagem

No editor do Canva:

1. Adicione uma fotografia ao projeto.
2. Clique sobre a imagem.
3. Procure a opção **Editar imagem**.

Dependendo da versão do Canva, as ferramentas podem aparecer em posições diferentes.

---

## 2. Localizando a Borracha Mágica

Depois de selecionar a imagem:

1. Clique em **Editar imagem**.
2. Procure pelas ferramentas de edição.
3. Localize a opção **Borracha Mágica**.

Ao selecionar a ferramenta, o Canva apresentará uma área para você indicar qual elemento deseja remover.

---

# 3. Como utilizar a ferramenta

A utilização é bastante simples.

Imagine que temos uma fotografia de uma pessoa e existe uma lata sobre uma mesa que queremos remover.

O procedimento será:

1. Abra a imagem no Canva.
2. Clique em **Editar imagem**.
3. Selecione **Borracha Mágica**.
4. Passe o pincel sobre o objeto que deseja remover.
5. Cubra toda a área do objeto.
6. Clique para aplicar a remoção.
7. Observe o resultado.

O Canva tentará preencher automaticamente o espaço onde estava o objeto.

---

# 4. Como utilizar o pincel

O tamanho do pincel é muito importante.

Se o pincel estiver muito grande, você poderá selecionar áreas que não deseja remover.

Se estiver muito pequeno, poderá ser necessário fazer várias seleções.

### Pincel grande

Utilize quando estiver removendo objetos maiores.

Exemplo:

```text
Pessoa inteira
Carro
Placa
Móvel
Objeto grande
```

### Pincel pequeno

Utilize para detalhes menores.

Exemplo:

```text
Mancha
Pequeno objeto
Espinha
Detalhe no fundo
Pequena imperfeição
```

---

# 5. Removendo uma pessoa do fundo

Um dos usos mais interessantes da Borracha Mágica é remover pessoas que aparecem ao fundo de uma fotografia.

Imagine uma fotografia em uma praia:

```text
        Pessoa principal

              ↓

        [ PESSOA ]

~~~~~~~~~~~~~~~~~~~~~~~~
   outra pessoa ao fundo
~~~~~~~~~~~~~~~~~~~~~~~~
```

Se queremos remover a pessoa que está ao fundo:

1. Abra a fotografia.
2. Selecione **Borracha Mágica**.
3. Ajuste o tamanho do pincel.
4. Pinte sobre a pessoa que deseja remover.
5. Tome cuidado para não selecionar a pessoa principal.
6. Aplique a remoção.
7. Observe como o Canva reconstruiu o fundo.

---

# 6. Removendo objetos

Outro exemplo é remover um objeto de uma fotografia.

Imagine uma mesa com um copo:

```text
+-----------------------+
|                       |
|       [ COPO ]        |
|                       |
+-----------------------+
```

Se queremos remover o copo:

1. Selecione a Borracha Mágica.
2. Passe o pincel sobre o copo.
3. Tente cobrir completamente o objeto.
4. Aplique a ferramenta.
5. Analise o resultado.

O Canva tentará reconstruir a região da mesa que estava atrás do copo.

---

# 7. Removendo pequenas manchas

A Borracha Mágica também pode ser utilizada para pequenas correções.

Por exemplo:

- Pequenas manchas no fundo;
- Pontos;
- Objetos pequenos;
- Marcas na parede;
- Pequenos elementos que aparecem na fotografia.

Porém, quando estamos trabalhando especificamente com **pele e rosto**, é importante ter cuidado.

Para remover uma pequena imperfeição, utilize um pincel pequeno e faça uma seleção precisa.

Evite selecionar uma área muito grande do rosto.

---

# 8. Exemplo: removendo uma mancha do rosto

Imagine uma fotografia de retrato em que existe uma pequena mancha na pele.

O procedimento pode ser:

### Passo 1

Selecione a fotografia.

### Passo 2

Clique em:

**Editar imagem → Borracha Mágica**

### Passo 3

Diminua o tamanho do pincel.

### Passo 4

Passe o pincel somente sobre a mancha.

### Passo 5

Aplique a ferramenta.

### Passo 6

Observe se a pele ficou natural.

Se o resultado ficar estranho, desfaça a alteração e tente novamente com uma seleção menor.

---

# 9. Por que o resultado pode ficar estranho?

A Borracha Mágica utiliza inteligência artificial para tentar descobrir **o que deveria existir na região que foi removida**.

Por exemplo:

```text
ANTES

┌───────────────────┐
│                   │
│      [ OBJETO ]   │
│                   │
└───────────────────┘
```

Depois da remoção:

```text
DEPOIS

┌───────────────────┐
│                   │
│    área recriada  │
│                   │
└───────────────────┘
```

O Canva precisa "imaginar" como era aquela região.

Se o fundo for simples, o resultado normalmente tende a ser melhor.

Se houver muitos detalhes, o resultado pode apresentar deformações.

---

# 10. Imagens simples x imagens complexas

## Imagem simples

Exemplo:

```text
Objeto + parede branca
```

A inteligência artificial possui bastante informação para reconstruir a área.

Resultado esperado:

**Bom**

---

## Imagem complexa

Exemplo:

```text
Pessoa + árvores + pessoas + carros + prédios
```

Nesse caso, existem muitos elementos diferentes próximos à área removida.

Resultado esperado:

**Pode exigir várias tentativas.**

---

# 11. Dica importante: faça pequenas seleções

Uma das melhores práticas para utilizar a Borracha Mágica é:

> **Não tente remover tudo de uma vez.**

Por exemplo, se você deseja remover uma pessoa:

Errado:

```text
████████████████████
████████████████████
████████████████████
```

Selecionar uma área muito grande pode remover elementos que deveriam permanecer.

Prefira trabalhar em pequenas partes:

```text
     cabeça
       ↓
      ███

     corpo
       ↓
      ███

     pernas
       ↓
      ███
```

Isso permite ter maior controle sobre o resultado.

---

# 12. Faça várias tentativas

Se a primeira tentativa não ficou boa, não significa que a ferramenta não funciona.

Você pode:

1. Desfazer a alteração.
2. Diminuir o pincel.
3. Selecionar uma área menor.
4. Aplicar novamente.
5. Avaliar o resultado.

A edição de imagens normalmente envolve **tentativa, observação e correção**.

---

# 13. Antes e depois

Uma boa prática durante uma edição é comparar a imagem original com a imagem modificada.

### Antes

```text
Fotografia original
        ↓
Objeto indesejado
```

### Depois

```text
Fotografia editada
        ↓
Objeto removido
```

Pergunte:

- A imagem continua natural?
- O fundo ficou deformado?
- Existem manchas artificiais?
- A textura foi preservada?
- O objeto realmente desapareceu?
- Alguma parte importante da imagem foi removida?

---

# 14. Atividade prática

## Desafio — Remoção de objetos

Escolha uma fotografia que contenha pelo menos **3 elementos que possam ser removidos**.

Por exemplo:

- Uma pessoa ao fundo;
- Um objeto sobre uma mesa;
- Uma placa;
- Uma lata;
- Uma pequena mancha.

### Tarefa

Utilizando a **Borracha Mágica**, faça a remoção dos três elementos.

Depois, compare:

**Imagem original × Imagem editada**

### O aluno deverá observar:

1. Se o objeto foi completamente removido;
2. Se o fundo ficou natural;
3. Se apareceram deformações;
4. Se alguma parte importante da fotografia foi alterada;
5. Se seria possível melhorar o resultado utilizando um pincel menor.

---

# 15. Atividade avançada

Agora escolha uma fotografia de uma pessoa em um ambiente com várias informações no fundo.

Tente remover:

- Uma pessoa;
- Um objeto;
- Uma pequena imperfeição.

Faça três versões da mesma edição:

### Versão 1

Utilizando um pincel grande.

### Versão 2

Utilizando um pincel médio.

### Versão 3

Utilizando um pincel pequeno.

Compare os três resultados.

### Pergunta

**Qual tamanho de pincel apresentou o melhor resultado e por quê?**

---

# 16. Boas práticas

Ao utilizar a Borracha Mágica:

- Sempre observe a imagem antes de começar;
- Utilize o tamanho de pincel adequado;
- Comece com seleções pequenas;
- Evite selecionar áreas desnecessárias;
- Faça várias tentativas;
- Utilize o desfazer quando necessário;
- Compare o antes e o depois;
- Observe se o resultado parece natural;
- Tenha cuidado ao editar rostos;
- Não exagere nas alterações.

---

# 17. Resumo

A **Borracha Mágica** é uma ferramenta utilizada para remover elementos de uma fotografia.

O processo básico é:

```text
Selecionar imagem
       ↓
Editar imagem
       ↓
Borracha Mágica
       ↓
Ajustar pincel
       ↓
Selecionar objeto
       ↓
Aplicar remoção
       ↓
Avaliar resultado
       ↓
Corrigir se necessário
```

O mais importante é entender que a ferramenta não simplesmente "apaga" o objeto. Ela tenta **reconstruir a região removida utilizando inteligência artificial**.

Por isso, a qualidade do resultado depende da imagem, do tamanho da área removida e da complexidade do fundo.

A melhor forma de aprender é praticar com diferentes fotografias e experimentar diferentes tamanhos de pincel.
