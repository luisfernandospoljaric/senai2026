# Lei Geral de Proteção de Dados (LGPD)

A Lei Geral de Proteção de Dados (LGPD) — Lei nº 13.709/2018 — é a legislação brasileira que regula a coleta, o armazenamento, o tratamento e o compartilhamento de dados pessoais por empresas, organizações e órgãos públicos.

Seu principal objetivo é **proteger a privacidade e os direitos dos cidadãos**, garantindo mais transparência e segurança no uso das informações pessoais.

## Dados Pessoais
Dados pessoais são informações que podem identificar uma pessoa, como:
- Nome
- CPF
- Endereço
- Telefone
- E-mail
- Endereço de IP

## Dados Sensíveis
São dados que exigem maior proteção, pois podem gerar discriminação, como:
- Origem racial ou étnica
- Religião
- Opinião política
- Dados de saúde
- Dados biométricos

## Agentes da LGPD
A lei define três papéis principais no tratamento de dados:

- **Titular:** pessoa dona dos dados.
- **Controlador:** responsável por decidir como os dados serão utilizados.
- **Operador:** responsável por processar os dados em nome do controlador.

## Direitos do Titular
A LGPD garante vários direitos ao cidadão, como:
- Saber quais dados estão sendo armazenados
- Solicitar correção de dados incorretos
- Solicitar exclusão de dados
- Revogar consentimento
- Saber com quem seus dados foram compartilhados

## Fiscalização
A fiscalização da lei é feita pela **Autoridade Nacional de Proteção de Dados (ANPD)**, responsável por orientar, fiscalizar e aplicar penalidades.

## Penalidades
Empresas que não cumprem a LGPD podem sofrer punições como:
- Advertência
- Multas de até **2% do faturamento**, limitadas a **R$ 50 milhões por infração**
- Bloqueio ou exclusão dos dados

## Conclusão
A LGPD é fundamental para garantir **segurança, transparência e privacidade** no uso de dados pessoais na era digital, estabelecendo regras claras para organizações e protegendo os direitos dos cidadãos.
