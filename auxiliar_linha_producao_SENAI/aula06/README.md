## PARTE 1 — LGPD

A Lei Geral de Proteção de Dados Pessoais (LGPD) é a Lei nº 13.709/2018. Ela estabelece regras para o tratamento de dados pessoais e tem como objetivo proteger direitos fundamentais relacionados à liberdade, privacidade e ao desenvolvimento da personalidade.
