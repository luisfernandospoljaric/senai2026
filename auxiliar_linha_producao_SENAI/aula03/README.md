# 1. O que é Software?

Software é a **parte lógica do computador**, composta por programas, aplicativos e sistemas que controlam o hardware.

>  Se o hardware é a parte física, o software é a parte inteligente que dá funcionamento à máquina.

Sem software, o computador não executa nenhuma tarefa.

---

# 2. Tipos de Software

Os softwares são classificados em três categorias principais:

## 2.1 Software de Sistema

Responsável por controlar o funcionamento do computador.

### Exemplos:
- Windows
- Linux
- macOS
- Android
- iOS
- Drivers

### Funções:
- Gerenciar memória
- Controlar o processador
- Organizar arquivos
- Controlar dispositivos

---

## 2.2 Software de Aplicação

Programas utilizados pelo usuário para realizar tarefas específicas.

### Exemplos:
- Microsoft Word
- Excel
- Google Chrome
- Photoshop
- WhatsApp

### Função:
Executar tarefas como edição de textos, navegação na internet, comunicação, etc.

---

## 2.3 Software de Programação

Ferramentas utilizadas para desenvolver outros softwares.

### Exemplos:
- Visual Studio Code
- PyCharm
- Eclipse
- Compiladores
- Interpretadores

---

# 3. Sistema Operacional (SO)

O Sistema Operacional é o **principal software do computador**.

Ele atua como intermediário entre o usuário e o hardware.

## Principais Funções:
- Gerenciar memória RAM
- Controlar o processador (CPU)
- Administrar arquivos
- Controlar dispositivos
- Executar programas

---

# 4. Sistema Operacional para Estação de Trabalho

Utilizado em:
- Computadores de escritório
- Notebooks
- Workstations profissionais

## Características:
- Uso com teclado e mouse
- Maior poder de processamento
- Instalação livre de programas
- Sistema de arquivos mais amplo
- Foco em produtividade

### Exemplos:
- Windows 11
- Ubuntu
- macOS

---

# 5. Sistema Operacional Mobile

Desenvolvido para:
- Smartphones
- Tablets
- Smartwatches

## Características:
- Interface touch (toque)
- Otimizado para bateria
- Aplicativos via loja oficial
- Maior controle de permissões
- Sistema mais restrito

### Exemplos:
- Android
- iOS

---

# 6. Diferença Entre SO Desktop e SO Mobile

| Característica | Estação de Trabalho | Mobile |
|---------------|--------------------|--------|
| Interface | Teclado e mouse | Toque |
| Instalação de programas | Livre | Loja oficial |
| Foco | Desempenho | Economia de bateria |
| Acesso ao sistema | Amplo | Restrito |
| Mobilidade | Fixo | Portátil |

---

# Conclusão

- Software é a parte lógica do computador.
- Existem três tipos principais: Sistema, Aplicação e Programação.
- O Sistema Operacional é o software mais importante.
- Sistemas para desktop focam em desempenho e produtividade.
- Sistemas mobile focam em mobilidade, segurança e economia de energia.
