# Segurança da Informação – Programas Maliciosos (Malware)

## O que é Malware?

**Malware** (Malicious Software) é qualquer programa criado com a intenção de causar danos, roubar informações, espionar usuários ou controlar sistemas sem autorização.

> Nem todo malware é vírus. O vírus é apenas um dos tipos existentes.

---

# Principais Tipos de Malware

## 1. Vírus
- Infecta arquivos
- Precisa ser executado para se espalhar
- Pode corromper ou apagar dados

## 2. Worm
- Se espalha automaticamente pela rede
- Não precisa de arquivo hospedeiro
- Pode infectar milhares de computadores rapidamente

## 3. Trojan (Cavalo de Troia)
- Se disfarça de programa legítimo
- Abre portas para invasores
- Não se replica sozinho

## 4. Ransomware
- Criptografa arquivos
- Exige pagamento para liberar acesso
- Muito comum em ataques a empresas

## 5. Spyware
- Espiona atividades do usuário
- Rouba senhas e informações pessoais

## 6. Adware
- Exibe propagandas excessivas
- Pode coletar dados de navegação

## 7. Keylogger
- Registra tudo que é digitado no teclado
- Usado para roubo de senhas

## 8. Rootkit
- Esconde a presença do malware
- Atua em nível profundo do sistema

## 9. Backdoor
- Cria acesso remoto oculto ao invasor

## 10. Bot / Botnet
- **Bot:** computador infectado controlado remotamente  
- **Botnet:** rede de computadores infectados usados para ataques

## 11. Scareware
- Falsos alertas de vírus
- Induz o usuário a comprar softwares falsos

## 12. Fileless Malware
- Atua na memória RAM
- Difícil de detectar

## 13. Cryptojacking
- Usa o computador da vítima para minerar criptomoedas

## 14. Logic Bomb (Bomba Lógica)
- Ativado por condição específica (data ou evento)

## 15. Exploit
- Explora falhas de segurança para invadir sistemas

---

# Resumo Comparativo

| Tipo        | Se Replica? | Objetivo Principal        |
|------------|------------|--------------------------|
| Vírus      | Sim        | Infectar arquivos        |
| Worm       | Sim        | Espalhar pela rede       |
| Trojan     | Não        | Enganar usuário          |
| Ransomware | Não        | Extorsão financeira      |
| Spyware    | Não        | Espionagem               |
| Rootkit    | Não        | Ocultação                |
| Botnet     | Sim        | Ataques em massa         |

---

# Como se Proteger

- Manter o sistema operacional atualizado  
- Utilizar antivírus confiável  
- Ativar firewall  
- Evitar downloads suspeitos  
- Não clicar em links desconhecidos  
- Fazer backups regularmente

# O que deve conter na apresentação?

Cada grupo deve explicar:

## 1. Definição
- O que é esse malware?  
- Quando surgiu?  
- Por que ele é perigoso?  

## 2. Funcionamento Técnico
- Como ele infecta o sistema?  
- Ele se replica?  
- Ele precisa de ação do usuário?  
- Atua em arquivo, rede ou memória?  

## 3. Caso Real

O grupo deve apresentar um caso real envolvendo esse tipo de malware.

Sugestões de exemplos:

- Ataque do ransomware WannaCry  
- Worm ILOVEYOU  
- Botnet Mirai  

Eles devem explicar:

- Quando aconteceu?  
- Quem foi afetado?  
- Quais foram as consequências?  
- Qual foi o prejuízo?  
- Como foi resolvido?
